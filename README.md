# 青岛港海铁联运数字孪生仿真

基于 Li 等（2023）与 Ji 等（2026）研究拓展的三维港口仿真网页。支持铁路—船舶双向逐箱追踪、设备监控、故障回看、方案对比，以及浏览器内的 Ji 海侧协同调度优化实验。

本项目使用合成任务与概化港区布局，未接入真实港口遥测；画面、指标与设备状态随仿真时钟变化。

公开演示入口：[青岛港数字孪生平台](https://cunniffestumb-web.github.io/qingdao-port-digital-twin/)。首次访问需等待仓库的 Pages 发布任务成功。

## 功能

- **港区全景**：三维铁路、空轨、AGV、堆场、岸桥与船舶；支持对象选择、跟随、近景、昼夜和二维视图。
- **逐箱追踪**：按箱号查看九环节旅程、承载设备、交接事件和等待原因。
- **设备与异常**：注入故障、修复、查看影响范围，并回看相应历史状态。
- **方案对比**：相同需求与观察期下比较运力、派工、通行及合成停车补能配置，保存和导出实验结果。
- **论文实验**：修改任务、车辆、作业位与时长参数；在本机浏览器求解，查看三维交接、设备/作业位甘特图、到离时刻与上下界，导出 JSON 和原式 LP。

## Ji 复现范围

Ji 原模型的海侧最小工期目标及已说明的车辆、双循环、同湾同步和轨道互斥约束，通过 **HiGHS 1.16.0 WASM 等价 MILP** 实现。原参数 12 箱算例已求得并证明最优工期 **41 分钟**，20 箱算例为 **71 分钟**。发表数值未作为求解答案或停止条件。

当前支持 1–10 对平衡任务、正整数分钟 T0–T4。预算未完成证明时会保留真实可行解与下界。原文 **E-LBBD 算法没有实现**；Li 的原始随机优化、SAA/S-ACO 与换电算法也没有实现。全链路停车补能是扩展模型。论文页的三维距离与区外转场为调度示意，不能视作真实道路轨迹。

[Ji 模型、等价性与证据](research/JI-OPTIMIZATION-MODEL.md) · [全链路模型说明](research/MODEL-SCOPE.md)

## 本地运行

需要 Node.js，无需安装 npm 依赖。

```sh
node scripts/serve.mjs
```

浏览器访问 `http://127.0.0.1:4173`。也可使用 `npm start`。Three.js、HiGHS、纹理与天空素材全部随站点提供，运行不依赖 CDN。

## GitHub Pages 部署

在仓库 **Settings → Pages** 中选择 **GitHub Actions**。`.github/workflows/pages.yml` 在 `main` 更新后自动发布 `docs/`，也可从 Actions 页面手动运行。

首次发布会验证 `source-v15.zip` 的文件清单和校验值，把完整源代码导入仓库。已有 `docs/index.html` 时跳过导入，后续正常编辑文件即可，不会被旧源码包覆盖。`docs/.nojekyll` 保留静态文件原样发布。入口、模块、Worker、WASM 与素材均使用相对路径，适用于项目子路径站点。

## 目录与来源

- `docs/`：可直接发布的完整网页及本地依赖。
- `scripts/serve.mjs`：本地静态服务器。
- `research/`：模型解释、论文依据和实景/案例参考。
- `evidence/`：Ji 原图时序核验、独立枚举交叉验证与 20 箱求解证书。

论文：[Li 等（2023）](https://doi.org/10.1016/j.tre.2023.103110)、[Ji 等（2026）](https://doi.org/10.1016/j.tre.2025.104485)。原始论文不随仓库分发。证据中的本机原始 PDF 路径已缩为文件名，论文校验值未修改。

Three.js 与 HiGHS 的 MIT 许可位于各自 `docs/vendor/` 目录；材质和天空素材的 CC0 来源与校验记录见 [credits.json](docs/assets/surfaces/credits.json)。本仓库未对自主代码另行授予开源许可证；公开可查看不等同于额外授权。
